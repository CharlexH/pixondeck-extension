# Branding and media

The Apache-2.0 license covers original code and documentation in this repository.
PixOnDeck names and logos identify the official product. The code license does
not grant permission to imply that a third-party distribution is official or endorsed.
Accurate statements of origin and legally permitted uses remain allowed.

The visual assets under `assets/` and `src/assets/` are supplied for building,
redistributing and documenting this client. They are not licensed as a standalone
stock-media or branding collection. Modified public distributions should use a
name and visual identity that clearly distinguish them from the official product.
This policy does not add restrictions to the Apache-licensed source code.

The stock photographs under `docs/examples/` retain their CC0 dedication;
see [photo credits and provenance](docs/examples/README.md). The PixOnDeck
branding policy does not apply to those third-party photographs.
