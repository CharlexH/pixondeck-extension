# Contributing

Start with a reproducible issue for bugs or provider compatibility. Include Chrome version, client version, expected behavior and sanitized reproduction steps. Never attach API keys, tokens, private images or production environment files.

Small fixes and documentation improvements are welcome. Discuss larger changes first; this is the official PixOnDeck client and must remain compatible with its hosted services. A contribution does not guarantee production deployment or store release.

Run `npm ci`, `npm run typecheck`, `npm test`, and `npm run build`. Use the fixture preview for interface work and describe which real-browser checks you performed. Keep changes focused. Third-party additions must retain their licenses and attribution; update generated notices when dependencies change.

Contributions to original code and documentation are submitted under Apache-2.0. Do not contribute code or media you lack permission to share. See BRANDING.md for visual asset scope.
